# Модуль проверки туннелирования (Tunnel Verifier)

## Обзор

Модуль проверки туннелирования (`tunnelverifier`) реализует функциональность для проверки, что неРУ трафик корректно направляется через VPN-туннель. Модуль запускает процессы проверки и мониторит их состояние, обеспечивая надежность туннелирования трафика.

## Архитектура

Модуль состоит из следующих компонентов:

- `TunnelVerifier` - основной компонент, управляющий процессами проверки
- `Config` - конфигурация модуля (интервалы проверки, целевые эндпоинты)
- `IPLeakDetector` - детектор утечек IP-адресов
- `DNSLeakDetector` - детектор утечек DNS-запросов
- `RoutingVerifier` - верификатор маршрутизации трафика
- `Logger` - расширенный логгер с поддержкой уровней и JSON-формата
- `Metrics` - система сбора метрик производительности

## Функциональность

### Проверка туннелирования

Модуль периодически выполняет проверки, чтобы убедиться, что:

1. НеРУ трафик направляется через VPN-туннель
2. Процессы проверки работают корректно
3. Нет утечек трафика
4. Система уведомлений работает корректно

### Проверка утечек

- **IP-утечки**: Проверка, что внешний IP-адрес соответствует ожидаемому VPN-серверу
- **DNS-утечки**: Проверка, что DNS-запросы направляются через зашифрованный туннель
- **Маршрутизация**: Проверка, что неРУ трафик корректно направляется через туннель

### Управление процессами

- Автоматический запуск процессов проверки
- Мониторинг состояния процессов
- Перезапуск упавших процессов
- Корректное завершение при остановке VPN

### Логирование и мониторинг

- Подробное логирование всех операций
- Мониторинг состояния процессов
- Уровни логирования (debug, info, warn, error)
- Интеграция с системой логирования клиента
- Поддержка JSON-формата логов

### Система метрик

- Сбор статистики по проверкам туннелирования
- Измерение времени выполнения проверок
- Отслеживание успешных и неудачных проверок
- Мониторинг производительности

### Система уведомлений

- Интеграция с модулем `internal/alerts`
- Отправка уведомлений о сбоях туннелирования
- Отправка уведомлений о восстановлении туннелирования
- Поддержка разных уровней важности уведомлений

## Интеграция с машиной состояний

Модуль интегрирован с машиной состояний VPN клиента:

- Запускается при переходе в состояние `StateRunning`
- Останавливается при переходе в состояния `StateStopping` или `StateIdle`
- Состояние проверки туннелирования доступно через интерфейс машины состояний
- Отправка уведомлений при изменениях состояния туннелирования

## Конфигурация

Модуль использует следующие параметры конфигурации:

- `CheckInterval` - интервал между проверками
- `Timeout` - таймаут для каждой проверки
- `VerificationEndpoints` - список эндпоинтов для проверки
- `TestPayload` - тестовая нагрузка для проверки
- `LogLevel` - уровень логирования (debug, info, warn, error)
- `IPCheckService` - сервис для проверки внешнего IP
- `CheckIPLeak` - включить проверку IP-утечек
- `CheckDNSLeak` - включить проверку DNS-утечек
- `VerifyRouting` - включить проверку маршрутизации
- `EnableComprehensiveLeakDetection` - включить комплексное обнаружение утечек
- `EnableAdvancedRoutingVerification` - включить расширенную проверку маршрутизации

## Использование

```go

    CheckInterval: 30 * time.Second,
    Timeout:       60 * time.Second,
    VerificationEndpoints: []string{"8.8.8.8", "1.1.1.1"},
    TestPayload:   "TUNNEL_TEST",
    LogLevel:      "info",
    CheckIPLeak:   true,
    CheckDNSLeak:  true,
    VerifyRouting: true,
}

tv, err := tunnelverifier.New(config)
if err != nil {
    // обработка ошибки
}

// Установка логгера
tv.SetLogger(your_logger)

ctx := context.Background()

if err != nil {
    // обработка ошибки

// Проверка валидности туннелирования
isValid, err := tv.IsTunnelingValid()

    // обработка ошибки
}

// Получение метрик
metrics := tv.GetMetrics()

// Остановка проверки
err = tv.Stop(ctx)
```

## Примеры использования

### Пример 1: Базовое использование

```go
// Создание конфигурации с минимальными настройками
config := tunnelverifier.Config{
    CheckInterval: 30 * time.Second,
    Timeout:       60 * time.Second,
    VerificationEndpoints: []string{"8.8.8.8", "1.1.1.1"},
    LogLevel:      "info",
    CheckIPLeak:   true,
    CheckDNSLeak:  true,
    VerifyRouting: true,
}

// Создание экземпляра проверяющего туннель
tv, err := tunnelverifier.New(config)
if err != nil {
    log.Fatalf("Ошибка создания TunnelVerifier: %v", err)
}

// Запуск проверки туннелирования
ctx := context.Background()
err = tv.Start(ctx)
if err != nil {
    log.Printf("Ошибка запуска проверки: %v", err)
}

// Периодическая проверка валидности туннелирования
for {
    isValid, err := tv.IsTunnelingValid()
    if err != nil {
        log.Printf("Ошибка проверки: %v", err)
    } else if !isValid {
        log.Println("Обнаружена проблема с туннелированием!")
        // Здесь можно выполнить действия по восстановлению VPN-соединения
    }
    
    time.Sleep(30 * time.Second) // Проверка каждые 30 секунд
}
```

### Пример 2: Использование с системой уведомлений

```go
// Создание конфигурации с максимальной безопасностью
config := tunnelverifier.Config{
    CheckInterval: 15 * time.Second,
    Timeout:       30 * time.Second,
    VerificationEndpoints: []string{
        "1.1.1.1", "8.8.8.8", "208.67.222.222",
        "www.google.com", "www.cloudflare.com",
    },
    LogLevel:      "debug",
    CheckIPLeak:   true,
    CheckDNSLeak:  true,
    VerifyRouting: true,
}

tv, err := tunnelverifier.New(config)
if err != nil {
    log.Fatalf("Ошибка создания TunnelVerifier: %v", err)
}

// Запуск проверки
ctx := context.Background()
err = tv.Start(ctx)
if err != nil {
    log.Printf("Ошибка запуска проверки: %v", err)
}

// Настройка проверки с уведомлениями об изменениях состояния
previousState := false
for {
    currentState, err := tv.IsTunnelingValid()
    if err != nil {
        log.Printf("Ошибка проверки: %v", err)
    } else {
        // Обнаружение изменений состояния
        if currentState && !previousState {
            // Восстановление туннелирования
            log.Println("Туннелирование восстановлено")
            // Можно отправить уведомление через систему alerts
        } else if !currentState && previousState {
            // Потеря туннелирования
            log.Println("Туннелирование потеряно - возможна утечка трафика!")
            // Отправить уведомление о критической проблеме
        }
        
        previousState = currentState
    }
    
    time.Sleep(10 * time.Second)
}
```

```go
    log.Fatalf("Ошибка создания TunnelVerifier: %v", err)

    // Получение статистики
    stats := tv.GetVerificationStats()
    log.Printf("Статистика проверок: %+v", stats)

    ipStats := tv.GetIPLeakCheckStats()
    log.Printf("Статистика проверок IP-утечек: %+v", ipStats)
    
    // Получение статистики по DNS-утечкам
    dnsStats := tv.GetDNSLeakCheckStats()
    log.Printf("Статистика проверок DNS-утечек: %+v", dnsStats)
    
    // Получение статистики по маршрутизации
    routingStats := tv.GetTrafficRoutingStats()
    log.Printf("Статистика проверок маршрутизации: %+v", routingStats)
    
    time.Sleep(60 * time.Second) // Сбор метрик каждую минуту
}
```
