## 🚀 Фаза 1: Предварительная проверка

- [ ] Операционная система: Ubuntu 20.04/22.04 или CentOS 8/9
- [ ] Доступный RAM: минимум 512 MB
- [ ] Доступный диск: минимум 2 GB
- [ ] Docker: версия 20.10 или выше
- [ ] Docker Compose: версия 2.0 или выше

### 1.2 Бэкапы

## 📦 Фаза 2: Установка и настройка uv/uvx

### 2.1 Установка uv
- [ ] Установлен uv: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- [ ] Добавлен в PATH: `export PATH="$HOME/.cargo/bin:$PATH"`
- [ ] Проверена версия: `uv --version`
- [ ] Проверена версия uvx: `uvx --version`

### 2.2 Системная установка (опционально)
- [ ] Создан системный symlink: `sudo ln -sf $HOME/.cargo/bin/uv /usr/local/bin/uv`
- [ ] Создан системный symlink: `sudo ln -sf $HOME/.cargo/bin/uvx /usr/local/bin/uvx`
- [ ] Проверена работоспособность системного uv: `sudo uv --version`
- [ ] Проверена работоспособность системного uvx: `sudo uvx --version`

### 2.3 Настройка pyproject.toml
- [ ] Создан файл `pyproject.toml`
- [ ] Настроены зависимости в секции `[project.dependencies]`
- [ ] Настроены опциональные зависимости
- [ ] Настроены скрипты в секции `[project.scripts]`
- [ ] Настроен uv в секции `[tool.uv]`
- [ ] Проверена валидация файла: `uv pip check`

## ⚙️ Фаза 5: Systemd сервисы

### 5.1 Установка systemd сервисов
- [ ] Скопированы файлы сервисов в `/etc/systemd/system/`
- [ ] Установлены права: `sudo chmod 644 /etc/systemd/system/xvpn-*.service`
- [ ] Перезагружен systemd: `sudo systemctl daemon-reload`
- [ ] Включены сервисы: `sudo systemctl enable xvpn-*.service`

### 5.2 Тестирование сервисов
- [ ] Запуск API сервиса: `sudo systemctl start xvpn-api.service`
- [ ] Запуск Agent сервиса: `sudo systemctl start xvpn-agent.service`
- [ ] Запуск Bot сервиса: `sudo systemctl start xvpn-bot.service`
- [ ] Запуск Worker сервиса: `sudo systemctl start xvpn-worker.service`
- [ ] Запуск Traefik сервиса: `sudo systemctl start xvpn-traefik.service`

### 5.3 Проверка статуса
- [ ] Статус API сервиса: `sudo systemctl status xvpn-api.service`
- [ ] Статус Agent сервиса: `sudo systemctl status xvpn-agent.service`
- [ ] Статус Bot сервиса: `sudo systemctl status xvpn-bot.service`
- [ ] Статус Worker сервиса: `sudo systemctl status xvpn-worker.service`
- [ ] Статус Traefik сервиса: `sudo systemctl status xvpn-traefik.service`
