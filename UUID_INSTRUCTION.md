# Инструкция по использованию XVPN клиента

## Получение правильного UUID

Для работы с сервером XVPN необходимо использовать правильный UUID, который выдается телеграм-ботом сервера.

### Как получить UUID:
1. Напишите команду `/get_config` в телеграм-боте сервера
2. Бот вернет конфигурационные данные, содержащие ваш уникальный UUID
3. UUID будет выглядеть примерно так: `a1b2c3d4-e5f6-7890-abcd-ef1234567890`

## Установка правильного UUID

### Вариант 1: Через GUI (рекомендуется)
```bash
# Запустите GUI клиент:
python3 chatvpn_gui.py

# Нажмите кнопку "Сменить UUID"
# Введите полученный UUID из телеграм-бота
# Клиент автоматически сохранит новый UUID и перезагрузит конфигурацию
```

### Вариант 2: Замена в файле client.conf
```bash
# Откройте файл client.conf и замените UUID на полученный из бота
nano /home/uss/xvpn_client/client.conf

# Или используйте команду:
echo "ваш-uuid-из-бота" > /home/uss/xvpn_client/client.conf
```

### Вариант 3: Использование с аргументом
```bash
# Запустите клиент с новым UUID:
python3 run_with_uuid.py ваш-uuid-из-бота
```

## Запуск клиента с правильным UUID

После получения и установки правильного UUID:

```bash
# Для запуска с детализированным логированием:
python3 run_simple_client.py

# Или для запуска с GUI:
python3 chatvpn_gui.py

# Или с параметром UUID:
python3 run_with_uuid.py ваш-uuid-из-бота
```

## Проверка подключения

После запуска с правильным UUID:

1. Клиент должен успешно получить конфигурацию с сервера
2. Статус изменится на "running"
3. Внешний IP-адрес должен измениться
4. Система будет использовать один из доступных транспортов

## Устранение неполадок

Если клиент не подключается:

1. Проверьте правильность UUID
2. Убедитесь, что сервер доступен
3. Проверьте файл client.json - там должны быть правильные адреса сервера
4. Посмотрите логи в папке logs/
5. Попробуйте команду `python3 run_simple_client.py` для детализированного лога

## Текущий статус поддерживаемых транспортов

- XRay Reality TCP
- Hysteria2 UDP  
- VLESS TCP
- ShadowSocks TCP
- WireGuard TCP

Все транспорты должны работать после получения правильной конфигурации с сервера.
