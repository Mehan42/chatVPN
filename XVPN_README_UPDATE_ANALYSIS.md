## Правила для работы с большими файлами

### 1. Разбивка на подзадачи
- При работе с файлами > 500 строк разбивать задачу на подзадачи
- Работать с каждым фрагментом по отдельности
- Использовать целевые diff-ы для конкретных секций

### 2. Последовательное редактирование
- Изменять только одну секцию за раз
- Проверять синтаксис после каждого изменения
- Сохранять целостность структуры файла

### 3. Валидация изменений
- После завершения операции проверять целостность кода
- Убедиться, что все ссылки корректны
- Проверить форматирование markdown

### 4. Инкрементальные изменения
- Избегать сложных multi-file diff-ов
- Использовать apply_diff только для конкретных изменений
- Каждый diff должен быть независимым и понятным

### 5. Документирование
- Фиксировать все изменения в аналитическом документе
- Указывать причины и контекст изменений
- Сохранять историю модификаций
