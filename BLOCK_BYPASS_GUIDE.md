# Инструкция по настройке XVPN для обхода блокировок провайдера

## Контекст проблемы

- Провайдер локального ПК блокирует VPN
- Открытые только порты 80 и 443
- Требуется обход систем детектирования VPN
- На удаленном сервере неизвестны открытые порты

## Решение: Многоуровневая маршрутизация и протоколы

### 1. Использование порта 443 (HTTPS)

Все XVPN компоненты настроены на использование порта 443 (HTTPS) для имитации обычного HTTPS-трафика:

- API сервер: порт 443
- XRay: порт 443 с различными транспортами
- Клиент: подключение через порт 443

### 2. Поддерживаемые протоколы (6 типов)

XVPN поддерживает 6 различных протоколов для обхода блокировок:

1. **VLESS + WebSocket + TLS** - Обычный веб-трафик, трудно отличить от настоящего HTTPS
2. **VLESS + Reality** - Маскировка под легитимные HTTPS-сайты (Google)
3. **Trojan** - Имитация HTTPS-трафика с паролем вместо UUID
4. **VMess + WebSocket + TLS** - Классическая маскировка под веб-трафик
5. **Shadowsocks + TLS** - Шифрование с TLS-оберткой
6. **Hysteria2** - Адаптивная скорость, имитация UDP-трафика

### 3. Настройка сервера

#### Установка XRay с поддержкой всех протоколов:

```bash
# Установка XRay
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install --beta

# Копирование конфигурации XRay
sudo mkdir -p /usr/local/etc/xray
sudo cp xray_config.json /usr/local/etc/xray/config.json

# Перезапуск XRay
sudo systemctl restart xray
```

### 4. Настройка клиента

Клиент автоматически переключается между доступными протоколами:

- Проверяет доступность каждого протокола
- Оценивает качество соединения
- Выбирает оптимальный протокол
- Переключается при проблемах

### 5. Обратная маршрутизация (для обхода блокировок)

#### Настройка на удаленном сервере:

XRay сервер уже настроен для приема различных протоколов на порту 443 и маршрутизации их к интернету.

#### Настройка на локальном ПК:

```bash
# Установка клиентской части
python3 -m venv client_env
source client_env/bin/activate
pip install -r requirements_client.txt

# Копирование конфигурации клиента
mkdir -p ~/chatvpn/client
cp example_client_config.json ~/chatvpn/client/client.json

# Редактирование конфигурации (заменить your-remote-server.com на реальный адрес)
# Также заменить все placeholder'ы на реальные значения

# Запуск клиента
python3 client/vpn_client.py start
```

### 6. Автоматический выбор протокола

Клиентская машина состояний автоматически:

- Проверяет доступность всех протоколов
- Оценивает качество соединения
- Переключается между протоколами при блокировке
- Оптимизирует скорость и безопасность

### 7. Тестирование

После настройки можно проверить:

```bash
# Проверка статуса клиента
python3 client/vpn_client.py status

# Проверка доступности сервера
curl -k https://your-remote-server.com:443/mcp/v1/vpn.health

# Проверка соединения
curl --socks5 127.0.0.1:1080 https://httpbin.org/ip
```

### 8. Безопасность

- Все соединения шифруются через TLS
- Используется маскировка под легитимный HTTPS-трафик
- Нет сохранения логов (при правильной настройке)
- Используется несколько резервных протоколов

### 9. Мониторинг

Система автоматически:
- Отслеживает качество соединения
- Оповещает о переключениях протоколов
- Логирует все события для диагностики
