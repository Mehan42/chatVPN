# XVPN Client

Клиентская часть XVPN системы.

## Архитектура

- `config/` - конфигурационные файлы
- `scripts/` - скрипты установки и управления
- `profiles/` - профили подключения
- `logs/` - логи подключений
- `temp/` - временные файлы
- `bin/` - исполняемые файлы

## Установка

1. Запустите скрипт настройки:
   ```bash
   ./scripts/configure_client.sh
   ```

2. При необходимости добавьте дополнительные серверы:
   ```bash
   ./scripts/add_server.sh
   ```

## Получение конфигурации

1. Получите UUID клиента через Telegram-бота
2. Запустите скрипт получения конфигурации:
   ```bash
   ./scripts/get_config.sh
   ```

## Подключение

1. Запустите клиент:
   ```bash
   ./scripts/start_client.sh
   ```

2. В реальной реализации будет использоваться Xray/V2Ray для подключения:
   ```bash
   xray run -config /path/to/profile.json
   ```

## Многосерверная архитектура

Конфигурационный файл поддерживает подключение к нескольким серверам с возможностью автоматического переключения.
