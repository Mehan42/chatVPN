### 🚀 Deployment Instructions
```bash
# 1. Clone repository
git clone https://github.com/Mehan42/chatVPN.git /opt/xvpn
cd /opt/xvpn

# 2. Install dependencies
./scripts/install_server_dependencies.sh

# 3. Generate TLS certificates
./scripts/generate_tls_certs.sh

# 4. Deploy certificates
./scripts/deploy_certificates.sh

# 5. Install systemd services
./scripts/install_systemd_services.sh

# 6. Generate API tokens
./scripts/generate_api_tokens.py generate-defaults

# 7. Start services
systemctl start xvpn-api xvpn-agent xvpn-bot

# 8. Test deployment
./scripts/test_production_server.py
```
