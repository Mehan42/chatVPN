# XVPN Client Go

XVPN Client - это кроссплатформенный VPN-клиент с интеллектуальной маршрутизацией трафика, написанный на Go.

## Особенности

- **Маршрутизация трафика**: Автоматическое разделение РУ и неРУ трафика
- **Множество транспортов**: Поддержка VLESS, VMess, Trojan, Shadowsocks, WireGuard и других протоколов
- **Интеллектуальное переключение**: Автоматическое переключение между транспортами при сбоях
- **Безопасность**: Встроенные механизмы проверки маскировки
- **GUI**: Интуитивный графический интерфейс
- **Кроссплатформенность**: Сборка под Linux, macOS, Windows
- **Интеграция с сервером**: Полная интеграция с XVPN API для получения конфигурации и мониторинга

## Архитектура

Проект состоит из следующих модулей:

- `internal/state` - Машина состояний для управления подключением
- `internal/geoip` - Модуль маршрутизации трафика (РУ/неРУ)
- `internal/transport` - Управление транспортами
- `internal/config` - Система конфигурации
- `internal/logging` - Система логирования
- `internal/gui` - Графический интерфейс
- `internal/api` - Клиентская библиотека для работы с XVPN API
- `internal/health` - Система мониторинга здоровья
- `internal/alerts` - Система алертов и уведомлений
- `internal/updater` - Система обновлений
- `internal/proxy` - Система прокси

## Сборка

# Сборка для macOS

```bash

```

## Использование

Клиент автоматически определяет тип трафика (РУ или неРУ) и направляет его соответствующим образом:
- РУ трафик направляется напрямую через провайдера
- неРУ трафик направляется через удаленный сервер VPN

## Функции

### Маршрутизация трафика
- Определение принадлежности IP к РУ регионам
- Встроенные GeoIP базы
- Поддержка CIDR диапазонов

### Управление транспортами
- Автоматический выбор лучшего транспорта
- Проверка здоровья транспортов
- Резервное переключение

### Безопасность
- Проверка маскировки подключения
- Мониторинг утечек IP/DNS
- Шифрование трафика

### Мониторинг сервера
- Хаотичная проверка доступности сервера (30-300 секунд)
- Автоматическое восстановление после сбоев

### Интеграция с сервером
- Полная интеграция с XVPN API
- Получение конфигурации с сервера
- Регистрация клиентов (для администраторов)
- Периодическое обновление конфигурации

## Конфигурация
