#### **2. Инструкция по ручному тестированию**

##### **Шаг 1: Установка Mikrotik RouterOS**
```bash
# 2.1 Запуск Mikrotik RouterOS Docker контейнера
docker run -d \
  --name mikrotik \
  --privileged \
  -p 2000:2000 \
  -v mikrotik-data:/rw \
  mikrotik/routeros:latest

# 2.2 Подключение к Mikrotik CLI
docker exec -it mikrotik /tool/winbox

# 2.3 Базовая настройка Mikrotik
/system setup
set name=XVPN-Test
set timezone-name=manual
set time-zone-offset=+07:00
```

##### **Шаг 2: Настройка Nginx с SNI маршрутизацией**
```bash
# 2.1 Установка Nginx
docker run -d \
  --name nginx-sni \
  -p 443:443 \
  -p 80:80 \
  -v /opt/xvpn/nginx.conf:/etc/nginx/nginx.conf:ro \
  nginx:1.25-alpine

# 2.2 Конфигурация Nginx SNI
cat > /opt/xvpn/nginx.conf << 'EOF'
stream {
    map $ssl_preread_server_name $backend {
        "vpn.xvpn.test" xvpn_vpn;
        "api.xvpn.test" xvpn_api;
        "bot.xvpn.test" xvpn_bot;
        default xvpn_api;
    }

    upstream xvpn_vpn {
        server 172.17.0.2:8443;
        server 172.17.0.3:8443 backup;
    }

    upstream xvpn_api {
        server 172.17.0.4:8443;
        server 172.17.0.5:8443 backup;
    }

    upstream xvpn_bot {
        server 172.17.0.6:8443;
        server 172.17.0.7:8443 backup;
    }

    server {
        listen 443;
        proxy_pass $backend;
        ssl_preread on;
        proxy_protocol on;
        access_log /var/log/nginx/xvpn_stream.log;
    }
}
EOF
```

##### **Шаг 3: Развертывание XVPN**
