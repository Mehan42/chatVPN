# Структура проекта XVPN после реализации гибкого развертывания

## Обзор
После реализации системы гибкого развертывания структура проекта XVPN была значительно улучшена для поддержки установки в произвольные директории и автоматического обновления.

## Основные изменения

### 1. Унификация путей в клиентах
Все файлы в директории `client/` были обновлены для использования относительных путей вместо жестко заданных абсолютных путей `~/chatvpn/client/...`.

Пример:
```python
# Было:
CONFIG_PATH = os.path.expanduser("~/chatvpn/client/client.json")
LOG_DIR = Path.home() / 'chatvpn' / 'client' / 'logs'

# Стало:
CLIENT_DIR = Path(__file__).parent if '__file__' in globals() else Path.cwd()
CONFIG_PATH = CLIENT_DIR / 'client.json'
LOG_DIR = CLIENT_DIR / 'logs'
```

### 2. Исправление импортов Python
Относительные импорты были заменены на абсолютные для совместимости с запуском вне контекста пакета:
```python
# Было:
from .discover import discover_transports

# Стало:
import discover
# Использование: discover.discover_transports()
```

### 3. Скрипты гибкого развертывания
Созданы новые скрипты для установки в произвольные директории:

#### Клиентские скрипты:
- `install_client_flexible.sh` - Гибкая установка клиента
- `copy_updated_client.sh` - Синхронизация обновлений из разработки
- `run_client_fixed.py` - Исправленный скрипт запуска клиента

#### Серверные скрипты:
- `install_server_flexible.sh` - Гибкая установка сервера
- `advanced_deployment_watcher.py` - Расширенная система автоматического обновления
- `deployment_watcher.py` - Базовая система отслеживания обновлений

#### Вспомогательные утилиты:
- `fix_syntax_errors.py` - Исправление синтаксических ошибок после замены путей
- `update_client_paths.py` - Обновление путей в файлах клиента

## Команды для работы с системой

### Установка клиента в произвольную директорию:
```bash
./install_client_flexible.sh -d /opt/my_xvpn_client
```

### Установка сервера:
```bash
sudo ./install_server_flexible.sh -d /opt/xvpn
```

### Запуск клиента:
```bash
cd /opt/my_xvpn_client
python3 run_client.py
```

### Автоматическое обновление:
```bash
cd /opt/xvpn
python3 advanced_deployment_watcher.py --config deployment_config.json
```

### Синхронизация обновлений из разработки:
```bash
./copy_updated_client.sh
```

## Преимущества новой системы

1. **Гибкость установки** - клиент и сервер могут быть установлены в любую директорию
2. **Автоматическое обновление** - система отслеживает изменения в репозитории и обновляет компоненты
3. **Кроссплатформенность** - унифицированные пути работают на всех поддерживаемых платформах
4. **Надежность** - исправлены проблемы с импортами и запуском вне контекста пакета
5. **Документированность** - полное руководство по гибкому развертыванию
6. **Совместимость** - сохранена обратная совместимость со старыми установками
