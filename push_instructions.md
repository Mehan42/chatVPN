# Инструкции по пушу в репозиторий GitHub

Для выполнения пуша в репозиторий GitHub выполните следующие шаги:

1. Добавьте удаленный репозиторий:
   git remote add origin <URL_вашего_репозитория_GitHub>

   Например:
   git remote add origin https://github.com/ваш-аккаунт/ваш-репозиторий.git

2. Выполните пуш в ветку "тест":
   git push -u origin тест

Где:
- <URL_вашего_репозитория_GitHub> - это HTTPS или SSH URL вашего репозитория на GitHub
- "тест" - это имя ветки, в которую будет выполнен пуш

Примечание: Убедитесь, что у вас есть права на запись в указанный репозиторий.
