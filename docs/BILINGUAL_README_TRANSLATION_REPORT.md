## Структура двуязычных документов

Каждый двуязычный документ следует единой структуре:

```
# Заголовок документа

[English](#english) | [Русский](#russian)

---

## English {#english}

[Английский контент]

---

## Russian {#russian}

[Русский контент]

---
```

## Преимущества двуязычного формата

### 1. Универсальная доступность
- Пользователи могут выбирать удобный им язык
- Сохранена полная функциональность документации на обоих языках

### 2. Единый источник правды
- Все изменения отражаются в обоих языковых версиях
- Нет рассинхронизации между переводами

### 3. Простота навигации
- Четкие якорные ссылки для переключения между языками
- Структурированное содержание с одинаковыми разделами

### 4. Поддержка SEO
- Английские заголовки {#english} и русские заголовки {#russian}
- Поддержка поисковых систем с учетом языковых предпочтений
