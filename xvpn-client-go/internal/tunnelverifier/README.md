# Модуль проверки туннелирования (Tunnel Verifier)

## Обзор

Модуль проверки туннелирования (`tunnelverifier`) реализует функциональность для проверки, что неРУ трафик корректно направляется через VPN-туннель. Модуль запускает процессы проверки и мониторит их состояние, обеспечивая надежность туннелирования трафика.

## Архитектура

Модуль состоит из следующих компонентов:

- `TunnelVerifier` - основной компонент, управляющий процессами проверки
- `Config` - конфигурация модуля (интервалы проверки, целевые эндпоинты)
- `Process` - представление отдельного процесса проверки

## Функциональность

### Проверка туннелирования

Модуль периодически выполняет проверки, чтобы убедиться, что:

1. НеРУ трафик направляется через VPN-туннель
2. Процессы проверки работают корректно
3. Нет утечек трафика

### Управление процессами

- Автоматический запуск процессов проверки
- Мониторинг состояния процессов
- Перезапуск упавших процессов
- Корректное завершение при остановке VPN

## Интеграция с машиной состояний

Модуль интегрирован с машиной состояний VPN клиента:

- Запускается при переходе в состояние `StateRunning`
- Останавливается при переходе в состояния `StateStopping` или `StateIdle`
- Состояние проверки туннелирования доступно через интерфейс машины состояний

## Конфигурация

Модуль использует следующие параметры конфигурации:

- `CheckInterval` - интервал между проверками
- `Timeout` - таймаут для каждой проверки
- `VerificationEndpoints` - список эндпоинтов для проверки
- `TestPayload` - тестовая нагрузка для проверки

## Использование

```go
config := tunnelverifier.Config{
    CheckInterval: 30 * time.Second,
    Timeout:       60 * time.Second,
    VerificationEndpoints: []string{"8.8.8.8", "1.1.1.1"},
    TestPayload:   "TUNNEL_TEST",
}

tv, err := tunnelverifier.New(config)
if err != nil {
    // обработка ошибки
}

ctx := context.Background()
err = tv.Start(ctx)
if err != nil {
    // обработка ошибки
}

// Проверка валидности туннелирования
isValid, err := tv.IsTunnelingValid()
if err != nil {
    // обработка ошибки
}

// Остановка проверки
err = tv.Stop(ctx)
```

## Сценарии использования

### Проверка целостности туннеля

Модуль позволяет систематически проверять, что трафик из неРУ сегментов корректно направляется через VPN-туннель, выявляя возможные утечки или сбои в работе.

### Мониторинг работоспособности

Модуль контролирует работоспособность процессов проверки и может сигнализировать о проблемах с туннелированием.

## Потенциальные улучшения

1. Реализация конкретных проверок туннелирования
2. Интеграция с системой логирования
3. Поддержка различных методов проверки (DNS, HTTP, ICMP и др.)
4. Настройка параметров через основной конфигурационный файл клиента
