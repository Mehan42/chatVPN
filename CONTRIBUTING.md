# Contributing to XVPN

Thank you for your interest in contributing to XVPN! We welcome contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/chatVPN.git`
3. Create a branch for your feature: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -am "Add your feature"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Write docstrings for modules, classes, and functions
- Keep functions small and focused
- Write unit tests for new functionality

## Testing

Before submitting a pull request, please make sure:

1. All existing tests pass
2. New functionality includes appropriate tests
3. Code follows the established patterns
4. Documentation is updated if needed

Run tests with:
```bash
make test
```

## Reporting Issues

- Use the GitHub issue tracker
- Describe the issue clearly
- Include steps to reproduce
- Provide system information (OS, Python version, etc.)

## Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer
2. Update the README.md with details of changes to the interface
3. Increase the version numbers in any examples files and the README.md to the new version that this Pull Request would represent
4. Your Pull Request will be reviewed by maintainers
5. After review, you may be asked to make changes
6. Once approved, your Pull Request will be merged

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. 
By participating in this project you agree to abide by its terms.

## Questions?

Feel free to ask questions in the issues or contact the maintainers directly.
