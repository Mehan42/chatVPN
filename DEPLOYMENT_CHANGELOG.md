# История изменений (CHANGELOG)

## [Unreleased]

### Добавлено
- Система гибкого развертывания для клиентов и серверов
- Автоматическое обновление с отслеживанием коммитов
- Поддержка установки в произвольные директории
- Расширенная документация по развертыванию (FLEXIBLE_DEPLOYMENT_GUIDE.md)

### Изменено
- Унификация путей в клиентах с использованием относительных путей
- Исправление >50 синтаксических ошибок в файлах клиента
- Замена относительных импортов на абсолютные для совместимости
- Обновление скриптов запуска для работы вне контекста пакета

### Исправлено
- Проблемы с запуском клиента вне контекста пакета
- Ошибки в синтаксисе после автоматической замены путей
- Неправильные кавычки и скобки в строковых литералах
- Дублирующиеся строки в файлах

## [1.2.0] - 2025-10-09

### Добавлено
- `advanced_deployment_watcher.py` - Расширенная система автоматического обновления
- `deployment_config.json` - Конфигурационный файл для системы обновлений
- `install_client_flexible.sh` - Скрипт гибкой установки клиента
- `install_server_flexible.sh` - Скрипт гибкой установки сервера
- `copy_updated_client.sh` - Скрипт копирования обновлений
- `fix_syntax_errors.py` - Скрипт исправления синтаксических ошибок
- `run_client_fixed.py` - Исправленный скрипт запуска клиента
- `FLEXIBLE_DEPLOYMENT_GUIDE.md` - Документация по гибкому развертыванию

### Изменено
- `update_client_paths.py` - Улучшена система замены путей
- `deployment_watcher.py` - Добавлена поддержка конфигурационных файлов

## [1.1.0] - 2025-10-04

### Добавлено
- `update_client_paths.py` - Скрипт обновления путей в файлах клиента
- `deployment_watcher.py` - Базовая система отслеживания обновлений
