- `systemd/xvpn-api.service` - API сервис с uvx
- `systemd/xvpn-agent.service` - агент с uvx
- `systemd/xvpn-bot.service` - бот с uvx
- `systemd/xvpn-worker.service` - воркер с uvx
- `systemd/xvpn-traefik.service` - Traefik сервис

**Документация:**
- `docs/uv_integration_guide.md` - руководство по интеграции
