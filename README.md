# XVPN Client

XVPN - это продвинутый VPN клиент с поддержкой множества транспортных протоколов и автоматического переключения между ними.

## Особенности

- Поддержка множества транспортных протоколов: XRay Reality, Hysteria2, VLESS, ShadowSocks, WireGuard
- Автоматическое переключение между транспортами при сбое
- Поддержка IPv6 и dual-stack режима
- Режимы прокси (HTTP, SOCKS5)
- Система мониторинга и логирования
- Многоуровневая машина состояний для управления подключением

## Архитектура

### Основные компоненты

- `vpn_client.py` - Основной клиент с интеграцией state machine
- `transport_manager.py` - Менеджер транспортов с автоматическим переключением
- `state_machine.py` - Машина состояний для управления подключением
- `ipv6_manager.py` - Управление IPv6 подключением и dual-stack режимом
- `proxy_modes.py` - Управление различными режимами прокси
- `chatvpn_backend.py` - Взаимодействие с бэкендом (XRay, конфигурации)

### Транспортные протоколы

- **XRay Reality TCP** - Высокобезопасный протокол с обфускацией под HTTPS
- **Hysteria2 UDP** - Протокол с адаптивной скоростью и обфускацией
- **VLESS TCP** - Легковесный протокол от XRay
- **ShadowSocks TCP** - Шифрованный прокси-протокол
- **WireGuard TCP** - Современный VPN протокол (через TCP обертку)

## GUI интерфейс

GUI интерфейс является основным способом управления клиентом XVPN. Он предоставляет полный контроль над VPN подключением и включает следующие функции:

- Визуальный индикатор статуса подключения (ON/OFF)
- Отображение текущего IPv4 и IPv6 адреса
- Индикатор уровня безопасности с оценкой (от 1 до 5 звезд)
- Поддержка IPv6 с индикатором статуса
- Индикатор режима прокси с цветовой индикацией
- Отображение скорости подключения (входящая/исходящая)
- Кнопки управления подключением (вкл/выкл VPN)
- Кнопка запроса обновления конфигурации
- Кнопка изменения UUID клиента

### Запуск GUI

```bash
python3 chatvpn_gui.py
```

**ВАЖНО:** GUI требует графическую среду (X11/Wayland) для отображения окна интерфейса.

### Управление через GUI

**ВАЖНО:** Для полноценной работы клиента необходим правильный UUID, который выдается телеграм-ботом сервера через команду `/get_config`.

Самый простой способ установить или изменить UUID - через GUI интерфейс:

1. Запустите GUI клиент: `python3 chatvpn_gui.py`
2. Нажмите кнопку "Сменить UUID"
3. Введите полученный UUID из телеграм-бота

После установки UUID, клиент автоматически попытается получить конфигурацию с сервера и установить соединение.

### Запуск клиента

Клиент можно запускать как через GUI, так и через командную строку:

#### Простой запуск с логированием

```bash
python3 run_simple_client.py
```

#### Запуск с отладкой

```bash
python3 run_client_debug.py
```

#### Запуск с указанным UUID

```bash
python3 run_with_uuid.py ваш-uuid-из-бота
```

#### Тестирование функциональности

```bash
python3 test_vpn_functionality.py
```

### Статусы и индикаторы GUI

- **Статус подключения**: Показывает текущий статус VPN (ON/OFF)
- **IPv4 адрес**: Отображает текущий внешний IPv4 адрес
- **Индикатор безопасности**: Визуальный индикатор (●) с оценкой от 1 до 5 звезд
- **Индикатор IPv6**: Показывает статус поддержки IPv6 (зеленый - активен, серый - не поддерживается)
- **Индикатор режима прокси**: Показывает текущий режим прокси с цветовой индикацией
- **Скорость**: Отображает текущую скорость подключения (в КБ/с)



## Конфигурация

- `client.json` - Основная конфигурация клиента
- `transports/manifest.json` - Описание доступных транспортов
- `proxy_modes_config.json` - Настройки режимов прокси
- `ipv6_config.json` - Конфигурация IPv6

## Режимы прокси

XVPN поддерживает следующие режимы прокси:

- **SYSTEM** - Использование системных настроек прокси
- **MANUAL** - Ручные настройки прокси (HTTP/SOCKS5)
- **AUTO** - Автоматическое определение настроек
- **TRANSPARENT** - Прозрачный прокси
- **SPLIT** - Раздельная маршрутизация для приложений
- **BYPASS** - Обход прокси для определенных адресов

## Поддержка IPv6

Клиент полностью поддерживает IPv6 и dual-stack режимы:

- Автоматическое определение IPv6 подключения
- Поддержка IPv6 DNS серверов
- Маршрутизация IPv6 трафика
- Проверка IPv6 утечек

## Автоматическое переключение транспортов

Менеджер транспортов автоматически:

- Проверяет доступность текущего транспорта
- Переключается на резервный транспорт при сбое
- Обнаруживает доступные транспорты
- Оценивает производительность транспортов

## Полная архитектура приложения

XVPN - это полноценное приложение с клиент-серверной архитектурой, состоящее из:

1. **Клиентская часть (настоящий проект)**:
   - Представлена в данном репозитории
   - Отвечает за подключение к серверу и маршрутизацию трафика
   - Использует UUID для аутентификации и получения конфигурации

2. **Серверная часть**:
   - Должна быть развернута на отдельном сервере (обычно VPS)
   - Обрабатывает запросы клиентов и предоставляет конфигурации
   - Адрес по умолчанию: `https://uss.hopto.org:8443`
   - Отвечает по API-эндпоинтам вроде `/clients/{uuid}.json`

3. **Телеграм-бот**:
   - Используется для регистрации новых клиентов
   - Выдает уникальные UUID клиентам через команду `/get_config`
   - Связан с серверной частью для управления учетными записями

## Взаимодействие компонентов

1. При регистрации клиент получает UUID через телеграм-бота
2. Клиент использует этот UUID для аутентификации на сервере
3. По адресу `https://uss.hopto.org:8443/clients/{uuid}.json` клиент получает конфигурацию
4. На основе конфигурации клиент устанавливает соединение с транспортами

## Проблемы и ошибки

Если клиент не может подключиться к API серверу (например, "Не удалось подключиться к API серверу: https://localhost:8443" или "https://uss.hopto.org:8443"), это означает:

1. Сервер недоступен по данному адресу
2. Неправильный или отсутствующий UUID
3. Проблемы с сетью или фаерволом

## Gateway модуль

В проекте интегрирован "Gateway" модуль для интеллектуальной маршрутизации трафика:
- Определяет географическую принадлежность IP-адресов
- Направляет трафик в зависимости от страны назначения (Россия/не Россия)
- Использует GeoIP базы для определения местоположения
- Имеет встроенный TLS-туннель для маскировки под HTTPS-трафик

## Go-реализация клиента

В директории `xvpn-client-go` содержится Go-реализация клиента:
- Использует ту же архитектуру "шагов" (Steps) для обработки трафика
- Поддерживает те же транспортные протоколы
- Может использоваться как альтернатива Python-реализации
- Компилируется в один бинарный файл с помощью Makefile
