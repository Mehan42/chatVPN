## Технические характеристики

### Системные требования
- **OS:** Linux, Windows, macOS
- **Python:** 3.8+
- **Память:** минимум 512MB
- **Диск:** минимум 1GB
- **Сеть:** Стабильное интернет-соединение

### Поддерживаемые протоколы
- **VPN:** Xray, V2Ray
- **Транспорты:** WebSocket, TCP, gRPC
- **Сеть:** IPv4, IPv6
- **Безопасность:** TLS 1.2+, HTTPS

### Масштабируемость
- **Клиенты:** До 1000 одновременных подключений
- **Сервер:** До 10 000 клиентов
- **База данных:** SQLite (можно мигрировать на PostgreSQL)
- **Кэширование:** Redis (опционально)

## Руководство по установке

### 1. Автоматическая установка
```bash
# Linux
./installer/install_xvpn.sh

# Windows
installer/install_xvpn.bat
```

### 2. Ручная установка
```bash
# Установка зависимостей
pip3 install -r requirements.txt

# Копирование конфигураций
cp client/client.json.example client/client.json
cp server/config.json.example server/config.json

# Запуск сервисов
sudo ./scripts/install_systemd_services.sh
```

### 3. Запуск GUI
```bash
python3 client/chatvpn_gui.py
```

## Проблемы и ограничения

### Известные проблемы
1. **IPv6 поддержка** - Требуется дополнительная настройка сети
2. **TLS анализ** - Проблемы с некоторыми сертификатами
3. **Модули прокси** - Требует дополнительной реализации

### Ограничения
1. **Windows поддержка** - Требует администраторских прав
2. **macOS поддержка** - Требует подписи приложений
3. **Сетевые ограничения** - Может работать через restrictive networks
